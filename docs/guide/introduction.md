# 物理CDを使う家電として

PiCDPlayerは、CDを入れてTVリモコンで操作する据え置きプレイヤーを目指す。
音楽ライブラリの登録やdesktop操作を通常の利用手順にせず、物理discを操作の中心に置く。
CDが入っていない状態も、読み込み中も、装置が扱う普通の状態である。

この目的から、ネットワークで曲名を取得できることと、CDを再生できることを分けている。
曲名が見つからないdiscでも、TOCが読めればtrack番号と時間を使って再生できる。
CDを取り出す要求もdaemonが保持する。利用者が内部の読み取り処理を見計らって何度も
ボタンを押す必要をなくすためである。ただし故障したdriveを必ず開けられる保証ではない。

中心のcdplayerdはC++20で実装した単一processである。必要なblocking処理にはworkerを使う。
編集はMac、ビルドはDebian arm64 Docker、実機検証はRaspberry Pi OS Liteで行う。
将来専用imageへ移しやすいよう依存を限定している。
Buildrootやquiet boot、TV向け本番UIは現在の完成済み機能ではない。

もう一つの目標は、読み取ったPCMについて何が確認できたかを説明することにある。
音が出たという観測から、原盤と完全に一致するという結論へ飛躍しない。
この考え方は出力経路やmetadataの候補選択にも共通する。
